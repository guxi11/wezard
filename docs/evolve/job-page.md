# 工单页 —— 设计 (B3b ②, 按人定的方向落地)

前提: 工单的开工 / 收工不再发进群, 归在工单名下的派活和回执一律私聊。一批活怎么分下去、怎么交回来, 只在工单页里看。

人定的方向: **侧栏只做标记, 工单的一切都在右边的对话区里**。不加独立的「工单」侧栏视图, 侧栏里也不放工单列表。

## 入口: 三处, 都是点了就进

- **侧栏会话项上的 📋**: 一处往来里出现过工单的话 (群、私聊、群下的「我与它」那一项), 名字旁挂 📋, 有几张写几。点 📋 (不是点这一行): 只有一张就直接进那张工单页; 有多张就进工单列表, 只列这几张。
- **关系图连线上的 📋**: 一条关系上经手过工单, 卡片左上角的关系标签里多一枚 `📋` (几张写 `×N`), 不再另挂「工单 ×N」种类签。点它, 规则同上。
- **对话里的工单 badge**: 属于某张工单的派活、交回 (成员的答话) 和回执, 消息上挂一枚「📋 标题 + 进度」, 点了进那张工单页。工单页自己的消息不挂。

会话顶栏不再放工单按钮。

## 对话区

1. **工单页**: 开法和打开一段对话一样。顶栏写标题、编号、开单人、进度, 右边「‹ 回到 <进工单前那段会话>」。正文按时间排开:
   - 顶上一行开工框: 编号、标题、时刻、开工时的计划 (原样分行)。还开着的时候框里列出成员, 每人写状态 (在干 / 已交 / 反问 / 超时 / 失联 / 撤回)、名字 (点了切到它的视角) 和派给它的那句活。
   - 中间是归在这张工单名下的每一句: 派活、答话、回执 (回执标签「↩ 已交 · 第 2/3 份」, 点了跳回派活那句)。
   - 收工后底部多一个收工框: 成员的最终状态、交付了哪些文件、开单人写的结论。
2. **工单列表**: 视角开的或参与的工单 —— 只从一处多张的 📋 进来, 只列那几张; 没有「全部工单」入口, 「进行中」在前 (最近有动静的在前), 「已收工」在后 (整行淡一档, 最近收的在前)。
   每一行和会话列表同一种样子: 📋、标题、进度、最近一句、几分钟前。点一行进那张工单页; 顶栏的「‹ 回到 …」回到进工单之前那段会话。

## 开着和已收怎么区分

- **开着的**: 琥珀色进度 `已交 / 一共`, 比如 `1/3`。有人停在审批、反问或报错上时, 再挂一枚紫色「N 卡住」。
- **收了的**: 灰色「收工」, 在列表里淡一档, 工单页底部有收工框。
- 收工满 24 小时从账本清掉, 工单页和列表里就不再有它; 那些话仍在各自的私聊里。

## 和关系图的联动

正在看一张工单时切到关系图, 图上只亮它的当事人 (开单人和成员) 以及两头都是当事人的连线, 其余淡下去。选中态就是「正在看哪张工单」本身, 不另记。

## 删掉的旧展示

- 名片下的「在飞」托盘。
- 关系图顶上那排工单按钮。
- 会话列表里的「工单」栏。
- 日程页里的工单列表。名片上「📅 日程」的数字只算定时任务。
