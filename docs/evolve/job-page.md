# 工单页 —— 设计稿 (B3b ②)

前提: 工单的「开工 / 收工」两条气泡, 和归在工单名下的派活、回执, 以后都**不再进群**。
群里只剩人和 wizard 之间的对话; 一批活是怎么分下去、怎么交回来的, 只在工单页里看。
所以工单页要能单独讲清一件事的来龙去脉, 不靠群里的气泡补充。

> 现状: 下面写的大部分已经在 rolepage 上做出了一个可点的原型 (侧栏「工单」一栏、点开的时间线、关系图上方的工单条)。
> 这份是给人拍板用的。哪里不对, 改完设计再落地。

## ① 入口放在哪

一张工单有三个入口, 点进去是同一个页面:

1. **侧栏会话列表, 新的一栏「工单」**: 排在「群聊」「私聊」下面。只列和当前视角有关的工单, 也就是它开的、或它是成员的。
   每一行的样子和群聊一样: 📋 头像、工单标题、进度徽标、最近一句话、几分钟前、未读数。
2. **关系图上方的「工单条」**: 图上只要画出了某张工单的任何一个当事人 (开单的或成员), 这张工单就出现在条上, 一张一枚小按钮。
   点一下就打开这张工单, 同时图只亮它的成员。
3. **日程页的工单列表** (已有): 每一行改成可点, 点开同样进工单页。

## ② 一张工单页里有什么

右边的正文区和看一段对话一样, 从上往下按时间排:

- **顶栏**: 📋 工单标题, 下面一行小字写编号和开单的人 (点名字切到它的视角), 再加进度徽标 (见 ④)。
- **开工那一行**: 一条虚线框, 写「📋 J… 开工 · 标题 · 时刻」。
  还开着的时候, 框里列出全部成员, 每人一行: 状态 (在干 / 已交 / 反问 / 超时 / 失联 / 撤回), 名字可点, 再跟一句派给它的活。
- **中间的时间线**: 归在这张工单名下的每一句话, 都按普通聊天气泡画:
  - 开单的人派给成员的那句活;
  - 成员干完给出的答话;
  - 守护进程把答话送回开单人那一刻, 开单人那条消息的名字行上会挂一个 **「↩ 回执 · 已交 · 第 2/3 份」** 标签。
    点这个标签, 页面跳回当初派这件活的那一句, 并闪一下。
  - 成员自己再往下分派的活, 只要带着同一个工单号, 也在这里。
- **收工那一行**: 一条虚线框, 写「收工 · 时刻」, 下面是:
  - 成员清单, 写明各自的最终状态和交付了哪些文件;
  - 开单人写的收工结论, 按 markdown 渲染。

时间线不按视角的 session 切。成员各有各的 session, 一张工单要看全。

## ③ 和关系图、侧栏 chat list 怎么联动

规矩是**同一种东西只有一份实现**。工单行和群聊行、私聊行用的是同一套:
一行显示什么 (最近一句、几分钟前、未读) 由同一个函数算, 排序、选中、已读水位也走同一套。工单只多一个进度徽标。

- **选中态只有一份, 就是「当前打开的是哪个会话」**:
  - 在侧栏点一张工单 → 打开它。这时切到关系图, 图已经亮着这张工单的成员。
  - 在关系图的工单条上点一张 → 打开它。这时切回侧栏, 「工单」栏里那一行是选中的。
  - 在工单条上**再点一次**已选中的那张 → 放下这张工单, 回到视角自己那张卡片的对话。
- **关系图怎么亮**: 选中一张工单时, 它的成员和开单人的卡片照常显示, 其余卡片淡到三成。
  连线也一样: 两头都是这张工单当事人的那道线保留原色, 其余变成浅灰。
  如果有成员在当前这张图上没画出来 (比如只看「相关」时), 鼠标停在工单按钮上会提示「有 N 个成员不在这张图上」。
- **从工单页切视角**: 开工、收工框里的成员名字, 以及每条气泡的头像, 都能点, 点了换成那个 wizard 的视角。
  侧栏的「工单」栏只列和视角有关的工单。如果新视角不在这张工单里, 正文仍显示这张工单, 但侧栏那一栏里没有它。

## ④ 开着的工单和已收的怎么区分

- **进度徽标**:
  - 开着: 琥珀色, 写「已交份数 / 总份数」, 比如 `1/3`。总份数取成员人数和开工时说好的份数中较大的那个, 所以分身还没派齐时不会提前显示满。
  - 收了: 灰色, 写「收工」。
- **排序**: 和会话一样, 按最近有动静的排。开着的工单在干活, 自然浮在上面; 收了的慢慢沉下去。
- **页内**: 开着的工单只有开工那一行, 成员状态列在里面, 而且随时在变。收了的工单底部多一条收工框, 带结论和交付物。
- **留多久**: 收工满 24 小时的工单从账本里清掉, 侧栏和关系图都不再出现。它的时间线气泡还在各成员各自的对话里。
  这一条要不要改长, 请人定。

- 开工框里的成员状态只在打开页面时取一次, 不会实时刷新; 侧栏的进度徽标是实时的。
